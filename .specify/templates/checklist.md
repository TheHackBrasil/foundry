# Checklist — Spec NNNN — <área de risco>

Checklist avalia a **qualidade dos requisitos** (a spec), não o código.
Só crie quando a spec tocar uma área de risco (privacidade, publicação,
imutabilidade, afirmação factual). IDs `CHK###`.

## Requisitos — completude

- [ ] CHK001 Todo RF é verificável por comando ou inspeção direta?
- [ ] CHK002 Fora-de-escopo fecha as brechas óbvias (o que um leitor
      malicioso tentaria enfiar na entrega)?
- [ ] CHK003 Nenhum `[NEEDS CLARIFICATION]` restante sem resposta?

## Área de risco — <nome>

- [ ] CHK010 <pergunta sobre a qualidade do requisito, ex.: "todo conteúdo
      ilustrativo está rotulado (A7)?">
- [ ] CHK011 ...

## Veredito

- [ ] Spec apta para `plan` — ou lista do que falta escrever.
